# LoL Settings

LoLのゲーム設定・キー設定を保存して、別のアカウントに適用するWindows用ツールです。

## ダウンロード

[ダウンロードページ](https://github.com/tk-57/lol_settings/releases)の `LoLSettings.exe` をダウンロードして起動してください。

## 使い方

1. コピー元のアカウントでLoLにログインします。
2. ツールを起動し、「現在の設定を保存…」で設定を保存します。
3. コピー先のアカウントに切り替え、ツールの「再接続」を押します。
4. 「設定を適用…」で保存したファイルを選び、内容を確認して適用します。
